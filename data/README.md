# Data

Esta pasta separa dados históricos, saídas processadas e scripts de preparação.

- `raw/inmet/`: arquivos brutos do INMET.
- `processed/`: datasets consolidados usados no treinamento dos modelos.
- `scripts/`: rotinas de limpeza, consolidação e exportação de amostras.

Os scripts usam caminhos relativos à raiz do repositório, então podem ser executados de qualquer diretório.
